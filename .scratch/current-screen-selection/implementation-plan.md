## 02：设置入口与已有全局快捷键配置

Blocked by: None

交付：用户从主面板打开设置，查看全部现有键位及范围；编辑打开/收起与恢复的全局绑定，保存后生效、重启保留，失败时原键仍可用。

验收目标：

- 明确区分全局键、面板内键、保存值与当前生效状态；首个增量只展示可执行动作。
- 使用修饰键与主键控件编辑，支持禁用和恢复默认。录入不应触发待编辑动作或改变选窗状态。
- 重复组合、系统占用、保留键、未变化项、默认键占用均有对应反馈。
- 注册新组合成功但配置保存失败时，保留旧绑定与旧磁盘内容；设置使用原子配置替换。
- 重启读取、损坏配置反馈、逐动作冲突独立、退出释放均可验证。
- 保留现有普通选窗、局部布局、最近组与恢复行为；用现有真实输入与路由检查分别报告结果。

这是独立可用的增量：即使 A/B 尚未实现，用户也已能发现和配置当前快捷键。

## 03：A 排布本屏全部窗口与共享本屏执行保护

Blocked by: 02

交付：设置中加入 A，按推荐默认 Ctrl+Alt+1 或自定义组合，直接将触发时所在屏幕的合格窗口按自动布局排布；其他屏幕不参与，恢复仍使用最近一次实际修改前的快照。

验收目标：

- 触发前捕获前台/鼠标回退屏，操作期间固定目标；不把 PaneSet 面板位置作为目标依据。
- 前台优先，余下按上到下、左到右及此次候选顺序确定位置；普通、最大化与被遮挡窗口沿用候选规则。
- 零/一窗与任一目标格小于 240 × 160 物理像素时修改前拒绝，保留已有 Undo。
- 整组快照前与逐窗移动前复验完整身份、本屏归属及工作区域；不能仅依赖枚举过滤。
- 成员或目标环境执行中变化时，按规格报告跳过/停止、部分影响和可恢复范围。
- 主副屏双向检查只移动 fixture 本屏窗口，未参与窗口不变；连续排布和部分失败恢复仍可验证。
- 热键注册、实际按键、消息路由及操作 pending 分开记录；不以路由通过代替输入送达。

本任务交付共享的本屏执行保护和结果协调能力，供 B 使用。

## 04：B 原生本屏快速选窗

Blocked by: 02, 03

交付：设置中加入 B，按推荐默认 Ctrl+Alt+2 或自定义组合，每次出现本屏临时选窗层；点选可见标记或标题候选，检查顺序与布局，Enter 执行、Esc 取消。

验收目标：

- 每次新选择，合格前台默认 1 号；不因旧组或最近成功记录存在而直接执行。
- 可见且不误指的选择标记、顺序编号、常驻“所有窗口”入口；被遮挡或位置不确定的窗口通过标题候选选择。
- 点击由选窗层消费，选择操作不进入目标应用；同应用多窗、长标题、滚动、Tab/Space 可操作。
- Alt+1/2/3 只切预览，普通数字和其他组合不会误触发；零/一窗、失效成员、过小布局不可确认。
- 临时选择及预览不改变原生几何；确认才调用共享本屏执行路径。
- 已选成员关闭、最小化或移屏时显示失效并要求用户明确修改，不静默换成员或退化为 A。
- 初次激活失败、内部焦点切换与外部失焦有不同处理；Enter 不在未取得键盘焦点时被当作成功确认。
- 原生重现“应用一组 → 再进入 → 选择另一组并预览 → 取消 → 恢复”，验证已有布局和 Undo 保留。
- 层的关闭、单实例唤起、pending 与进程退出沿用主操作所有权，不新增独立 Undo 或持久窗口组。
- 真实系统输入、合成路由、截图/控件边界及人工物理键盘分别验收，保留历史输入不稳定。

03 是当前交付顺序中的共享能力前置；B 本质上依赖本屏执行保护，而不是 A 的按钮或快捷键。如果将来调整并行方式，应按共享能力重画依赖，不强迫 B 调用 A。

## 交付边界

三个增量已按上述依赖实施，共用原生操作与恢复记录。默认组合键、配置及焦点规则用于当前实现；用户明确接受的 B 每次选择/Enter/Esc 与受控检查、人工实机结论分别记录。

本轮未提交、推送或发布，也不将原型外观认可视作真实 Windows 验收通过。

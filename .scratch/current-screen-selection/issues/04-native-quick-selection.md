# 04：B 原生本屏快速选窗

Status: ready-for-agent
Progress: done

## What to build

原生桌面选窗层、可见窗口选择标记、遮挡窗口标题候选、编号及布局预览；每次新选择，Enter 确认、Esc 取消。依据[规格](../spec.md)。

Blocked by: 02, 03

## Acceptance criteria

- [x] 选择与预览不移动窗口，确认仅执行所选本屏目标；取消保留 Undo。
- [x] 保守可见标记、常驻所有窗口、同应用多窗、长标题、滚动及键盘可用。
- [x] 无效成员、零/一窗、过小布局阻止确认，不静默缩组。
- [x] 激活失败、内部焦点、外部失焦及覆盖层关闭生命周期明确。
- [x] 实际输入、合成路由、原生几何与受控截图分别记录。

## Comments

用户已明确授权原生实施。依赖 03 的共享本屏执行能力，不新增独立恢复管理器或持久窗口组。

原生透明选窗层已接入。quick-entry、quick-flow、quick-invalid、quick-input、global-quick-input、quick-activation-failure 与 mouse-routing 在完整回归中通过：包括真实按钮、真实全局 B、原生 Space/Alt/Enter/Esc、下拉框 Enter 分两次、布局/取消/Undo、外部失焦、覆盖层收到主按钮 down/up 而下层指示器不变。默认合格前台、每次新成员和本进程 B 布局记忆分别实现；关闭覆盖层后才提交共享执行。

修复 Show-only 全局 B 未转入前台的问题，仅做普通激活请求，保持实际前台/键盘检查；没有修改历史面板策略。受控鼠标检查按 SM_SWAPBUTTON 映射，不在物理按钮已按住时注入。长标题有限宽度换行、失效说明及设置底部图已读取；透明层图非完整桌面截图。选窗层激活失败 guard 通过，Main 的 OS 拒绝反馈没有可靠端到端负向设置，保留这项证据缺口。物理输入、第三方窗口、混合 DPI、显示拓扑与效率仍未人工验收，详见[验收记录](../../../docs/VALIDATION.md)。本轮三个增量实现完成，最后选窗源码的真实全局 B 定向检查再次通过；45/1/3 全套结果及五项收尾定向检查见验收记录。

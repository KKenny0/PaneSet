# B：A 排布后部分窗口缺少选择标记

Status: needs-info
Progress: in-progress

## 用户观察

先用 A 布局，再进入 B，右上方窗口没有可选择的按钮。用户认为 A 整体交互没有明显问题。

## 当前证据

QuickSelectWindow.RefreshCandidates 仅将标记放在目标窗口左上方；资格失败、可用宽度不足、底边越界及 MarkVisible 返回 false 均会隐藏。MarkVisible 使用更高层可见、非最小化、非系统隐藏窗口的原生外框，标记矩形有交集就拒绝，不尝试另一个锚点。

这些是源码路径，未重现用户此次状态，不能判定实际漏标记由哪个条件导致。已有受控输入检查不覆盖这次用户窗口组合。

## 下一步

- 确认缺少标记的窗口是否仍出现在“所有窗口”中，先区分候选过滤与标记呈现。
- 若在列表中，记录标记尺寸、工作区及遮挡拒绝原因；不因猜测放宽遮挡保护。
- 使用受控 fixture 重现对应几何/层级，再决定修改。

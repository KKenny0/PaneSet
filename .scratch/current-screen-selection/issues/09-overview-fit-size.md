# B：按候选数计算初始面板大小

Status: ready-for-agent
Progress: done

## 需求与实现

用户试用反馈 B 快捷键弹出全工作区大小面板，希望按当前屏幕实际窗口数采用合适大小。已直接授权此调整。

QuickSelectWindow.InitialBounds 根据捕获的合格候选数、目标工作区和目标 HWND 的 DPI 计算初始矩形。最多三列，卡片增多时增加高度，最多 900 DIP；工作区四周预留约 24 DIP，无法容纳时压到工作区内并由现有滚动承接。两窗常规为 968×560 DIP，三窗为 1258×560 DIP，四窗为 968×724 DIP。隐藏 HWND 先移到目标屏获取有效 DPI，再设最终居中位置。

只在进入时确定外框，搜索、选择和刷新不改变面板尺寸。源窗口排布仍使用原工作区，与选窗面板外框分开；DWM 仍用宿主客户区坐标，未改变裁切或 Undo。

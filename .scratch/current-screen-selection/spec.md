# 本屏快捷排布与快速选窗

阶段：用户已授权设置、A、B 三个增量，已加入 Windows 程序。实现与受控检查完成；真实输入及人工环境边界见[验收记录](../../docs/VALIDATION.md)。

## Problem Statement

用户认为当前大列表确实让选窗更快，但预期“最近组”的使用频率不高。程序缺少统一设置入口，用户不易发现和修改快捷键。用户还需要两种仅作用于当前显示器的操作：直接整理本屏全部窗口，或者临时选出其中几扇进行对照。

“最近组”低频是用户预期，不是调用统计；大列表有正向使用反馈，尚无完整任务耗时统计。

## Solution

提供统一设置入口，以及两个不同的全局快捷动作：

- **A：排布本屏全部窗口。** 收集当前屏幕全部合格窗口，直接执行自动布局。
- **B：本屏快速选窗。** 每次进入统一网格总览，点选内容卡片，或按应用名和标题搜索；右侧调整选择顺序。Enter 确认排布，Esc 取消。前轮标记版规则作为历史保留在下文。

用户明确接受 B 每次进入选窗的规则，取代早期“已有有效组时直接执行”的建议。选择与预览保持实际窗口位置；取消保留已完成的布局及恢复记录。现有跨屏大列表继续承担跨屏选择和复杂标题辨认。

原型：[quick-selection-prototype.html](../../designs/current-screen-selection/quick-selection-prototype.html)。用户反馈“看着不错”，记录为原型方向认可；未收到逐场景操作反馈。网页检查和真实 Windows 验收分别记录。

## 当前增量：B 统一网格总览（已接入，验收边界独立记录）

用户已确认 Q1–Q6，并在收口时回复「认可」授权实施。以下规则已接入；本文其余桌面标记规则保留为前轮实现记录，总览已替代其呈现部分。

1. 用统一尺寸卡片呈现本屏全部合格候选，包括被遮挡窗口；内容预览为主要辨认信息，应用名和标题辅助。预览不可用时保留可选的标题卡片，不能与窗口失效混为一谈。
2. 进入时合格前台卡片第一，其余按原桌面上到下、左到右；点击选择或标题变化不重新排列卡片。按本次捕获的候选数和目标屏工作区/DPI 计算初始面板尺寸并居中，少量窗口紧凑展示，大量窗口限制尺寸并滚动；搜索、勾选和刷新不使外框跳动。
3. 按选择顺序编号；右侧已选列表提供前移、后移，更新编号和最终布局预览，左侧卡片位置保持不变。取消成员后保留其他成员相对顺序，重新加入排到末尾。
4. 多窗口保持可辨认卡片尺寸，纵向滚动，不为塞入一屏无限缩小；搜索匹配应用名和标题。筛选不改变选组，右侧保留被筛选隐藏的已选成员，排布操作持续可达。
5. 沿用每次新选择、默认合格前台、固定本屏、至少两窗、既有布局与尺寸约束、Enter 确认、Esc 取消及共享执行/Undo。已选窗口失效时明确保留说明并阻止提交，外部失焦与显示环境变化继续按现有保护处理。
6. 选择、顺序调整、搜索及预览都不移动或激活源窗口，不覆盖已有 Undo。原生缩略图的宿主、遮挡兼容、DPI 和生命周期先做受控验证；技术限制单独记录，不把 HTML 模拟当作系统能力证据。

验收需覆盖同应用多窗辨认、遮挡窗、标题变化不跳位、顺序调整对应真实布局、筛选隐藏已选项、大量候选与低高度操作可达、预览降级和成员失效，以及既有取消/焦点/Undo 保护。原生定向检查和桌面合成截图已有证据，完整运行保留失败，详见任务 07 与验收记录。旧网页检查不覆盖未加入 HTML 的前移/后移操作。

方向记录见[问题 06](issues/06-overview-selection-direction.md)，能力边界见[DWM 调研](../../docs/RESEARCH_WINDOW_OVERVIEW.md)。漏标记仍由问题 05 独立跟踪；采用新呈现不证明旧缺陷根因已查明。

## User Stories

1. 作为用户，我希望从明确的设置入口查看所有快捷动作，以便知道 PaneSet 如何操作。
2. 作为用户，我希望看到全局键与面板内键的区别，以免在其他应用中使用错误键位。
3. 作为用户，我希望修改全局快捷键并在重启后保留，以便配合自己的工作习惯。
4. 作为用户，我希望看到保存键位与实际生效状态，以便知道是否存在占用冲突。
5. 作为用户，我希望新键注册或保存失败时原键仍可使用，以免一次设置修改破坏入口。
6. 作为用户，我希望恢复默认键位，并知道恢复后是否成功生效。
7. 作为用户，我希望按 A 直接整理本屏全部合格窗口，以便快速铺开资料。
8. 作为用户，我希望按 B 进入一次新的临时选择，以便更换对照对象。
9. 作为用户，我希望前台窗口在 B 中默认已选中，以便只补选其他资料。
10. 作为用户，我希望点选可见窗口的标记，以便直接利用眼前的窗口位置。
11. 作为用户，我希望从标题候选选择被遮挡的窗口，以免先翻出每扇窗口。
12. 作为用户，我希望看到编号、标题和顺序，以便知道每扇窗口在布局中的位置。
13. 作为用户，我希望使用键盘选择候选和切换布局，以便减少鼠标操作。
14. 作为用户，我希望确认前只显示预览，以便检查结果再执行。
15. 作为用户，我希望取消只丢弃这次选择，以免改变已有布局或恢复记录。
16. 作为用户，我希望 A 与 B 都限定于触发时确定的屏幕，以免其他屏幕被拉入。
17. 作为用户，我希望关闭或移屏的成员明确显示失效，以便自行修改选组。
18. 作为用户，我希望恢复最近一次实际排布前的位置，以便撤销 A 或 B。
19. 作为用户，我希望窗口不响应或只接受部分布局时得到真实反馈，以便理解哪些窗口还能恢复。
20. 作为用户，我希望选窗层未取得键盘焦点时有明确反馈，以免误以为 Enter 会确认布局。

## Implementation Decisions

以下实施规则已用于当前代码。原型方向已获认可；默认组合键、配置事务和焦点细节不等于用户逐键或逐条验收结论。

### 设置与快捷键

- 设置入口置于主面板的明确按钮中。三个增量已接入打开、恢复、A 和 B 四个全局动作，集中列出面板内固定键位。
- 推荐保留 Ctrl+Alt+Space 打开/收起、Ctrl+Alt+Z 恢复；A 推荐 Ctrl+Alt+1，B 推荐 Ctrl+Alt+2。网页中的单键 A/B 不作为正式默认全局键。
- 面板内 Alt+1/2/3、Ctrl+F、Alt+S、Enter、Esc 首版集中展示。局部键首版保持固定，避免改变文本输入及标准控件导航。
- 每个全局动作可重新录入组合键或禁用。组合要求至少一个修饰键和一个非修饰键；拒绝本程序动作之间的重复组合、仅修饰键、裸字母/数字和 Windows 保留的 F12。系统占用通过实际注册结果反馈。
- 保存到 `%LOCALAPPDATA%/PaneSet/settings.json`，采用版本 1 的 JSON：`version` 为整数 1，`shortcuts` 为动作对象；动作名为 `OpenPanel`、`Restore`，后续加入 `ArrangeScreen`、`SelectScreen`。每项含整数 `modifiers`（仅 Alt/Control/Shift/Windows 位）和虚拟键整数 `key`；显式 `null` 表示禁用，缺失动作采用该动作的默认绑定。仅注册当前增量已实现的动作，升级加入 A/B 时按这一规则读取旧配置。注册时附加不重复触发规则，不将其存入用户修饰键。只持久保存绑定，窗口身份、最近组和 Undo 保持进程内。
- 修改单项时，验证格式及自身重复，未变化项不重复注册。先尝试新组合的临时注册，保留旧组合；临时注册不执行动作。注册成功后写同目录临时配置并原子替换，保存成功才切换生效动作并释放旧组合。
- 新组合注册失败、序列化或保存失败时，释放临时注册、保留旧绑定及旧磁盘配置。若注册清理异常，明确显示诊断与实际注册状态，不能显示“已生效”；退出仍释放持有的所有注册。
- 恢复默认走同一修改事务；默认键也可能被占用，冲突不能显示为成功。启动时逐动作注册，区分保存值与实际生效状态，一项冲突不阻止其他动作。
- 配置损坏、未知版本或无效内容时反馈问题，以默认绑定运行；用户主动保存后才覆盖有问题的配置。未知动作名不执行，避免未来配置被误解。

### 当前屏幕与候选

- 触发时先捕获外部前台窗口；若它是当前候选中的合格窗口，使用其所属屏幕。前台属于 PaneSet 或不合格时，沿用现有鼠标所在屏幕回退。
- 本次目标固定为该屏幕及捕获的工作区域；移动鼠标、切换焦点或打开选窗层不重新选目标。窗口跨屏时按原生所属屏幕规则归属，不声称它原本完全位于该屏。
- 候选沿用现有筛选：当前虚拟桌面、普通或最大化、可调整大小的顶层应用窗口；排除 PaneSet、最小化、隐藏、工具/附属、全屏和其他桌面窗口。遮挡不排除。
- 本屏操作在整组快照前校验所有身份、屏幕归属和目标工作区域，首次修改前获取最新状态；每扇实际修改前再校验。当前跨屏排布接口仍可用于原流程，本屏动作必须显式进入受本屏约束的执行路径。
- 目标屏幕消失或工作区域改变时拒绝未开始的请求，不能转到另一屏。执行中环境变化则停止尚未开始的修改，报告部分结果并保留实际影响的恢复记录。
- 单窗执行中关闭或移屏时跳过并报告；其他仍有效成员可按逐窗语义继续。系统与外部应用仍可能在校验后自行改变状态，不承诺原子事务或绝对隔离。

### A：排布本屏全部窗口

- 直接执行自动布局，两三窗等宽，四窗起网格。
- 前台合格窗口为 1 号；其他成员按当前上到下、左到右排序，位置相同时保持此次候选顺序。不按应用名合并窗口。
- 零窗或一窗时反馈“至少需要两扇”，不修改位置或 Undo。任一目标格小于 **240 × 160 物理像素**时，修改前拒绝；该阈值限制目标布局，不能替代应用自己的最小尺寸。
- A 不把全部成员写入 B 的临时选择；下次 B 仍开始新选择。

### B：本屏快速选窗（前轮标记版记录）

当前总览替代本节的覆盖层/标记/所有窗口呈现；每次新成员、布局记忆、本屏执行、取消和焦点保护继续沿用。总览搜索框内 Enter 不提交，按钮上的 Enter 执行按钮，布局下拉沿用先接受选项再确认。

- 每次触发都开始新的临时选择，合格前台窗口默认 1 号；不自动沿用上次成员或最近组。首次布局为自动，其后沿用本进程内 B 最近使用的布局选项，与主面板的布局选项不自动同步；每次可用 Alt+1/2/3 切换等宽、主辅与网格预览。取消仍保留 B 的布局选项，但不改变已应用布局、Undo 或最近成功记录；明确退出后重置为自动。此布局记忆范围属于实施建议，尚非人工操作验收结论。
- 使用本屏选窗覆盖层、可点击选择标记与简短操作栏；操作栏常驻“所有窗口”、选择数量、布局、确认和取消。
- 标记明确对应一扇具体窗口并显示编号/标题提示。标记位置被遮挡或无法可靠确认时，只提供标题候选；不显示可能误指其他窗口的标记。
- 点击由选窗层接收，不把选择点击送入目标应用。选择与虚线预览不移动、还原或激活目标窗口。
- 候选显示应用名和完整标题，支持同应用多窗、Tab 焦点导航、Space 勾选；普通数字及额外修饰组合不能误切布局。候选多时滚动，长标题完整可读。
- 按选择先后编号，取消某成员后剩余顺序保持；重新加入排到末尾。采用与现有布局相同的计算规则，不设独立窗口数上限。
- 零窗、一窗、失效成员或无法容纳的目标布局均禁用确认。Enter 才提交实际排布；确认后退出选择覆盖层并沿用主操作反馈。
- 关闭、最小化或移到其他屏幕的已选成员保留失效说明、选择及顺序，停止确认；用户可明确取消该成员。同一身份重新符合本屏候选条件时自动恢复有效性及原顺序，其他条件满足后恢复确认资格，仍需用户最终确认。主动取消的成员不自动选回，再次选择时加入末尾。刷新不得静默缩小组或替换同应用其他窗口。此处按架构讨论确认澄清，与既有刷新行为一致。
- Esc 在提交前结束临时选择，保留实际布局、已有 Undo 和最近成功记录。提交后的 pending 是另一状态，Esc 不承诺撤销已经发出的原生请求。
- 焦点以完整选窗会话为范围：覆盖层、其拥有的布局控件和候选控件之间切换不取消。外部应用真正取得焦点时，结束尚未确认的选择。
- Enter 才提交实际排布；布局下拉框展开时第一次 Enter 仅接受选项，关闭时即使焦点在布局控件中也可确认。错误或无效 A 请求以不激活方式显示主面板反馈，避免状态仅留在最小化窗口中。
- 初次显示必须确认选窗层取得前台及键盘焦点后才进入可操作状态；失败时退出选择，以不激活方式显示主面板反馈，不强制抢前台、不把激活失败视为通过。

### 操作所有权与恢复

- 主面板继续协调排布请求、最终反馈和最近成功记录；WindowManager 继续持有原生操作、pending 与 Undo。设置界面和选窗层不维护第二份恢复快照。
- 所有入口共用忙碌保护。B 选窗期间暂停 A、恢复和冲突的设置变更；提交等待期间暂停新的选择、布局修改及排布。等待只表示尚未完成，不等于取消。
- 首次修改前读取整组最新状态，保留直接或间接受影响的窗口。部分失败逐窗报告，恢复仍按现有身份、桌面和显示环境校验并允许失败重试。
- 最近组仅在整组最终成功时更新；载入最近组仍是明确的主面板动作。取消 B、失败设置和无效 A 不改成功记录。

## Testing Decisions

复用既有受控窗口检查入口与 FixtureHost，在用户命令/UI 动作层验证可观察结果；配置检查使用临时目录。只移动 fixture 创建的窗口，不操作用户已有窗口。

- 设置：列出的范围和实际注册状态、重新绑定后新键可用/旧键释放、自身重复与系统占用、注册成功但保存失败的回滚、未变化项、禁用、恢复默认仍冲突、损坏配置、重启持久化和退出释放。
- A：主屏与副屏双向触发、普通/最大化、未参与的其他屏窗口不变、零/一窗拒绝、过多窗口尺寸拒绝、连续 A/B 的最新恢复。
- 本屏约束：筛选后或执行前成员移屏/关闭、目标区域改变、执行中变化的部分报告与 Undo；元数据注入与物理断屏验证分别标注。
- B：每次新选择、默认前台、标记只选对应身份、点击不传入应用、标题候选可选完全遮挡窗、同应用标题辨认、顺序、零/一窗、布局只预览、取消保留几何和 Undo、无效成员明确说明。
- 焦点：首次未能激活、内部控件切换、候选键盘导航、外部失焦退出；分别记录真实系统输入与合成消息路由。一次成功不关闭历史输入不稳定。
- 生命周期：pending 期间重入、重复启动、退出后的迟到结果与快捷键释放；关闭选窗层不能结束整个进程或清空已有恢复记录。
- 物理键盘、中文输入法、第三方应用、混合 DPI 和真实显示拓扑变化继续需要人工/对应实机环境。网页原型的 28 项通过只属于浏览器模拟。

验证沿用 `verify.cmd` 的完整与单项入口、Release 构建和原生探针。新增单项名称在实施时注册；检查失败保持失败，不能用延时、合成输入、放宽焦点断言或环境跳过掩盖。

## Out of Scope

多组持久保存、跨进程窗口身份重建、应用启动、全屏/最小化窗口纳入、每种布局独立全局键、持续联动缩放、自动提权、macOS 和正式发布。

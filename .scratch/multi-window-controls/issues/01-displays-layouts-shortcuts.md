# 多显示器与多窗快捷操作

Status: ready-for-agent
Progress: in-progress

## 用户反馈

多显示器使用不正常；缺少快捷入口；只支持两窗，更多窗口不好处理。

## 当前原因与改进范围

启动时保存一个显示器，窗口筛选排除其他显示器，刷新沿用旧屏幕。面板没有目标显示器选择，也没有全局快捷键。两窗限制分别写在布局计算、窗口操作及界面。

本轮处理当前虚拟桌面的普通窗口：列出所有屏幕的窗口，明确选择排布目标屏幕；任意两扇以上窗口提供自动布局、等宽并排、一主多辅和网格，自动布局在四窗以上使用网格。跨屏移动只对明确选择的窗口执行，恢复回各自原屏幕及显示状态。

Ctrl+Alt+Space 打开或收起面板，Ctrl+Alt+Z 恢复；面板内 Enter 应用、Alt+S 交换顺序、Ctrl+F 搜索。面板收起后保留运行及恢复记录，提供明确退出；快捷键冲突显示反馈并保留手动入口。

## 验证

沿用布局、真实受控窗口操作及界面检查，新增三窗与多窗网格、副屏排布、跨屏恢复、目标切换、实际快捷键与冲突/释放验证。仅移动验证进程的窗口，不移动用户原有窗口。实际显示器缩放与布局记录在验收文档。

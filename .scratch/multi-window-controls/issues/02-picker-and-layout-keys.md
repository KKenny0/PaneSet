# 大列表选窗与局部布局键

Status: ready-for-agent
Progress: done

## 确认与目标

Q1 大列表方向已确认，用户随后回复“那就按这个收敛范围确定 Q2”。本任务记录第一个设计增量，已完成实现与 /check 范围审查。

在同一面板让窗口更容易找到和选中，再通过局部键切换整组布局预览。最近组未实现时，本增量也必须能独立完成搜索、多选、排布和恢复。

## 范围

- 宽窗左侧列表与搜索、右侧布局及紧凑预览；窄窗默认折叠预览。正常尺寸以同时可见 6 至 8 个普通短标题窗口为目标。
- 默认 Alt+1 等宽、Alt+2 主辅、Alt+3 网格；选项旁显示提示。只切预览，Enter 或排布按钮执行。
- 保留自动布局、顺序轮换、完整搜索及长标题提示、目标屏幕、刷新保留身份和顺序、既有局部键及两个全局入口。
- 输入普通数字和中文不触发布局；操作未完成时，局部键与控件共用操作保护。
- 不加入最近组、独立弹窗、全局布局键或新运行依赖。

完整行为和验收以[规格](../spec.md)为准。

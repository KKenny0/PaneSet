# 在同一面板载入最近窗口组

Status: ready-for-agent
Progress: done

## 确认与目标

用户回复“那就按这个收敛范围确定 Q2”，确认主动载入最近组的轻量方案。此为第二个设计增量，已在[大列表与局部键](02-picker-and-layout-keys.md)之后实施并完成 /check 范围审查，沿用同一面板提供“调整最近组”按钮。

## 行为

- 只保留最后一次整组成功排布的具体成员、相对顺序、目标和布局，记录仅在当前进程内保留。收起保留，退出清除；无记录时按钮不可用。
- 本次排布请求在等待期间保留，收到最终整组成功结果才更新最近组。最终失败、部分失败或无效请求保留之前的最近组。成功但窗口状态没有实际改变时可以更新最近组元数据，旧恢复记录保留。
- 载入刷新候选和屏幕、清除搜索筛选、展示当前标题和匹配原身份的合格成员；只更新选择和预览，不移动窗口或覆盖恢复记录。
- 缺失成员明确报告，保留有效成员供确认或补选，不换成同应用其他窗口；不足两扇禁止执行。
- 原目标不可用时，重新选择目标后才执行，不自动改排另一屏幕。原目标工作区域变化时，显示当前目标并重算预览，通过正常排布确认。
- 实际执行前再次检查身份与环境，首次修改前读取整组最新状态。恢复仍针对最近一次有实际影响的排布；等待中禁止载入、布局切换或其他冲突操作。
- 普通唤起继续从当前前台窗口开始新选择；重复启动已有前台面板保留选择。最近组只由明确按钮载入。

完整规则见[规格](../spec.md)。不增加持久保存、多组、独立弹窗、自动选窗、启动应用或新的全局键。

- [MainWindow.xaml](../../../src/PaneSet/MainWindow.xaml)及[MainWindow.xaml.cs](../../../src/PaneSet/MainWindow.xaml.cs)：加入按钮、进程内组记录和载入行为，沿用现有控件更新与操作保护。
- 使用 WindowTarget 的完整身份与最新候选匹配；[WindowManager](../../../src/PaneSet/WindowManager.cs)在实际修改前的校验及恢复快照继续负责原生操作。此增量以不新增公共窗口操作接口或服务为约束。
- 最近组发布必须依赖可靠的终局结果：直接完成和 CompletePendingAsync 延迟完成两条路径都要区分整组成功、部分失败及预检失败。不得在 Pending 反馈时提前更新或丢弃本次请求。
- [最近组检查](../../../tests/PaneSet.Checks/RecentGroupChecks.cs)、[交互检查](../../../tests/PaneSet.Checks/InteractionChecks.cs)和[检查入口](../../../tests/PaneSet.Checks/Program.cs)加入复用与终局状态覆盖；结果更新到[验收记录](../../../docs/VALIDATION.md)。

## 验收

三窗跨屏成功后载入，成员、顺序、目标和布局正确，载入不改变原生几何或恢复记录。覆盖同应用多窗、标题变化、关闭或身份复用、最小化及其他桌面失效；加载后再失效仍被执行前检查拒绝。

覆盖原目标不可用、工作区变化、载入后手动移窗、连续有实际影响的布局及无变化成功。状态 S0 → S1 → S2 的恢复回 S1；无影响请求不清除旧恢复记录。真实断屏和混合 DPI 需受控显示环境，缺少环境时单列未验证，不能由静态预览代替。

覆盖部分失败保留之前最近组、更新本次实际受影响窗口的恢复记录；延迟成功只在终局发布最近组，延迟失败保留旧组。等待中的载入、布局键、排布及恢复不产生冲突操作。

覆盖普通唤起与明确载入的区别、重复启动保留选择、收起保留记录、退出重启无记录。加入定向检查后运行完整 `verify.cmd` 及原生 `tools/run.ps1 --probe`，并实际按键检查。只自动移动 fixture 窗口；保留真实 `shortcuts` 与合成 `shortcut-routing` 的结果区别。

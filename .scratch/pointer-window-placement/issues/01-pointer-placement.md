# 01 · 指向辅窗直接放置，保留手动备用入口

## 目标

实现 [功能规格](../spec.md)：当前源窗口保持激活，鼠标指向可见参照窗口，按现有单窗快捷键直接借用完整位置和大小；短暂描边反馈。无效目标轻提示且不动。主面板“选择其他位置…”保留列表和位置图作为备用。

规格是完整行为依据。实现提交为 `696a540`；完成情况与剩余实机验收分别记录，见 [实施记录](../implementation.md) 和 [任务 02](02-native-acceptance.md)。

## 实施范围

- 改接实际单窗快捷动作，触发时固定源、指针命中参照及目标状态，显示自身反馈前完成捕获。
- 复用现有系统观察边界、WindowManager 执行、最终读回、700 ms pending 和恢复，不另写位移或 Undo。
- 实现不激活且不阻挡鼠标/键盘的短暂反馈，失败与目标描边分开；保留终局结果反馈。
- 主面板按钮与设置说明匹配新的作用；手动选择器继续使用面板显示的源与提交时的当前参照。
- 保留现有未提交的 P2 修复、参考列表、位置预览、用户配置与其他文档 WIP。

## 完成条件

- [x] 首次使用、无需历史；实际快捷动作直接借位，不出现选择器或确认步骤。
- [ ] 同应用不同窗、内容/标题栏/边框、部分露出正确命中；复制整个参照可见边界。
- [x] 无效源/参照、不合格覆盖面及源自身不触发修改、不猜下方目标、不自动打开面板、不替换旧恢复记录。
- [x] 源/参照身份及目标几何在触发后固定；捕获到执行之间的参照变化被拒绝，鼠标后来移动不改选。
- [x] 直接路径首次修改前源失去前台则停止；手动选择器仍可通过既有普通激活完成放置。
- [ ] 描边及轻提示不抢前台、不截获输入、不进入候选，结束/退出后释放；不能用描边暗示失败操作成功。
- [ ] 普通/最大化源、普通/最大化参照、跨屏、工作区与 DPI 保护满足规格；只向源发出修改请求。
- [x] no-op/修改前失败保留旧恢复；部分变化/未知读回恰当保留源恢复，可读最终状态优先，两项 P2 回归保持。
- [x] 等待与重复触发共用操作保护，不启动冲突修改；最终结果正确收集。
- [ ] 备用入口的源展示、列表/搜索/位置图、键盘/取消与显式历史模式保持；布局位置和最近窗口组独立。
- [x] 自定义、禁用、冲突及其他快捷动作不回退，不添加配置或全局动作。
- [x] 测试通过生产动作入口及现有系统观察边界验证；真实几何、注入观察、合成路由、真实输入/焦点与物理显示环境分别报告。

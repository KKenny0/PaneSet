# 单窗放置（拖动投放）：实施规格

Status: ready-for-agent
Progress: implemented

基线：`47cb48bff7c830c467c3268568a08ab2e13e7756`（feat/windows-two-window）。本规格取代同目录旧版"最小实施规格"（快捷键呼出位置图方案，从未实施，原文见 git 历史）。逐条决定的来由见 [interaction-notes.md](interaction-notes.md)；术语见根目录 GLOSSARY.md。`ready-for-agent` 表示内容可供实现，不表示已获得编码、提交或发布授权。

## Problem Statement

桌面上已有排好的窗口，新打开一扇临时窗口（如 PDF）时，用户希望它一次到位地进入某个位置，位置和大小同时就绪。现有方式要么手工拖动再逐边缩放，要么重新整组排布。此前的"先把鼠标移到参照窗口、再按放置快捷键"交互难以理解，已被用户暂停；旧的快捷键位置图方案从未实施。用户需要一个冷启动即可用、操作连续、不依赖配置历史的单窗放置入口。

## Solution

按住辅助键（默认 Shift）拖动任意合格窗口的标题栏：指针所在屏幕上显示布局模板的投放分区和一排模板缩略图；指针划过分区即选中并显示放置预览，划过缩略图即切换模板并保持；保持辅助键按住、松开鼠标，窗口即移动并缩放到选中分区。原占用窗口留在后面，其他窗口不动。投放实际改变窗口后产生一次单窗恢复，可还原到拖动开始那一刻的状态。

### 入口与模式

- 在系统原生标题栏拖动期间，按住辅助键即进入投放；先按住辅助键再开始拖动同样生效，只看按住状态，与起手顺序无关。
- 辅助键默认单键 Shift，可在设置中自定义其他单键或组合键；不做连击节奏检测。按住检测读取键状态，不经全局快捷键注册，不占用现有 Ctrl+Alt+1/2、Ctrl+Alt+Space/Z 的注册位。
- 不按辅助键的拖动永远是普通拖动，PaneSet 不介入。
- 拖动途中松开辅助键：收起分区与预览，继续普通拖动，之后松开鼠标不投放。
- 拖动中按 Esc：沿用 Windows 自身取消——整次拖动取消，窗口回到拖动开始前位置；PaneSet 只收起显示，不额外处理，不改恢复记录。

### 投放分区与模板

- 分区由五个内置布局模板在指针当前所在屏幕的工作区现算得出：左右两栏（1:1）、三等分栏、主辅（左 2/3 + 右 1/3）、上下两栏、2×2 网格。反向变体首版不收录。
- 分区与排布历史、最近窗口组相互独立；从未整组排布过也可使用（冷启动可用）。
- 进入投放时显示本次运行内上次使用的模板；重启后回到默认"左右两栏"。模板选择不持久化——用户理由：选哪个模板通常取决于当时桌面的窗口打开状态。
- 拖动期间屏幕上显示五个模板缩略图；指针划过哪个缩略图，分区就切换成哪个模板并保持；划错可再划回。不需要换模板时缩略图条不干扰操作。设置页不设模板项。
- 命中以鼠标指针所在分区为准，整格可命中并显示放置预览；不按被拖窗口边缘或覆盖面积判断。
- 指针移到另一块屏幕，分区换到该屏按该屏工作区现算；源窗口原来在哪屏不影响，松手落在指针所在屏的分区。

### 资格、执行与恢复

- 源窗口沿用现有合格窗口规则：普通可调整大小顶层窗口（含最大化）；排除 PaneSet 自身、最小化、隐藏、工具/附属、全屏及其他虚拟桌面窗口。不合格窗口拖动时按住辅助键不显示分区，不弹提示，保持普通拖动。
- 投放只调整源窗口：移动并缩放到选中分区；原占用该区域的窗口留在后面，其他窗口的位置、大小和层级不动。
- 最大化源窗口先恢复正常再投放，恢复最大化属于实际修改。
- 投放实际改变窗口后，用本次单窗恢复替代旧恢复记录，沿用现有恢复入口与一级恢复规则；恢复目标是拖动开始那一刻的位置、大小及正常/最大化状态，不是松手前的中间位置。无实际变化（窗口已在分区几何上）不替换旧记录。
- 取消（Esc、松开辅助键后松手）与不合格源的尝试不产生恢复记录，也不影响最近窗口组。

## User Stories

1. 作为用户，我希望按住辅助键拖动窗口就能看到投放分区，以便不用记忆独立入口。
2. 作为用户，我希望先按住辅助键再去抓标题栏也能进入投放，以便按自己顺手的方式起手。
3. 作为用户，我希望不按辅助键时 PaneSet 完全不介入拖动，以便普通拖动行为不变。
4. 作为用户，我希望拖到一半松开辅助键就能放弃投放继续普通拖动，以便临时改变主意不产生后果。
5. 作为用户，我希望拖动中按 Esc 让窗口回到拖动开始前的位置，以便误拖一键撤销。
6. 作为用户，我希望从未用 PaneSet 排布过也能直接使用分区，以便冷启动场景可用。
7. 作为用户，我希望分区来自固定的五种布局模板，以便任何时候按住辅助键都看到可预期的分区。
8. 作为用户，我希望默认出现上次用过的模板，以便常用分区一步到位。
9. 作为用户，我希望指针划过缩略图就切换模板并保持，以便需要别的分区时不用中断拖动去设置里改。
10. 作为用户，我希望划错模板能再划回来，以便切换零成本可逆。
11. 作为用户，我希望指针进入哪格就选中哪格、整格可命中，以便不必瞄准小目标。
12. 作为用户，我希望指针移到另一屏分区就换屏现算，以便多屏间随意选择目标屏。
13. 作为用户，我希望松手后窗口的位置和大小同时就绪，以便省去手动缩放。
14. 作为用户，我希望原占用窗口留在后面、其他窗口不动，以便已布好的工作环境不被打乱。
15. 作为用户，我希望最大化窗口也能投放，以便临时窗口放进分区前不用先手工还原。
16. 作为用户，我希望按现有恢复操作就能回到拖动开始前的状态，以便投放错了可以撤销。
17. 作为用户，我希望恢复回到拖动前而不是松手前的中间位置，以便撤销结果符合直觉。
18. 作为用户，我希望无实际变化的投放不替换旧恢复记录，以便已有恢复能力不被无效操作覆盖。
19. 作为用户，我希望辅助键默认 Shift 并可自定义，以便与个别应用自身的修饰键拖动冲突时能换键。
20. 作为用户，我希望不合格窗口（工具窗口、全屏窗口等）拖动时只是普通拖动、不弹提示，以便不被无关反馈打断。
21. 作为用户，我希望拖动投放不更新最近窗口组，以便临时放置不影响整组复用。
22. 作为用户，我希望分区显示在被拖窗口之上且清晰可见，以便拖动途中始终知道会放到哪里。

## Implementation Decisions

### 模块与职责

- 新增拖动投放协调组件：观察系统移动/缩放事件（开始、结束）与辅助键状态、指针位置、屏幕几何，驱动一个纯交互状态机；状态机只消费观测数据流，输出进入投放、当前模板、命中分区、退出、提交，不直接调用系统接口。原生观察与状态机分离，状态机可用合成事件流检查。
- 分区计算复用现有布局引擎的整数分区算法，在单屏工作区上按固定分区数生成五种模板的分区；沿用物理像素坐标与既有间距规则。
- 单窗执行扩展现有原生执行器：接受源窗口身份与目标分区矩形，沿用现有可见边框换算、读回验证、最大化先还原、身份与目标环境校验、pending 互斥；恢复记录的建立与替换沿用现有管理器，不另设一套状态。
- 投放覆盖层为临时置顶的纯视觉层：绘制分区边框、选中高亮、放置预览和模板缩略图条；不取得焦点、不消费鼠标输入（拖动期间鼠标输入属于系统拖动循环），选择全部由指针位置驱动。
- 主面板、整组排布、A/B、恢复与设置行为不变；辅助键自定义放设置页与快捷键同区，说明其按住检测用途。

### 关键取舍

- 不做拖动中数字键或滚轮切换（需记忆或送达不可靠）；模板切换只用可见缩略图的指针划过。
- 模板选择不持久化：本次运行内记住上次使用，重启回默认左右两栏。
- 旧"最近成功布局位置记录"概念取消；旧快捷键位置图入口搁置，本功能是唯一单窗放置入口。
- 投放不修改原占用窗口的任何属性，只依靠把源窗口放到前面获得视觉前后。
- 分区不做最小尺寸前置拒绝：单窗投放失败影响面小，按应用自身限制执行并沿用读回与失败反馈；极小工作区的表现实现时实测确认。

## Testing Decisions

以外部行为为断言对象，不为私有方法建镜像检查。沿用现有 `-Check --case` 验证入口，注册新 case：

| 计划新增 case | 必须证明的外部行为 |
| --- | --- |
| drag-placement | 合格源（普通/最大化、同屏/跨屏）投放后几何与读回、原占用窗口留后、其他窗口不动、恢复替换与恢复目标正确。 |
| drag-placement-zones | 五种模板在不同工作区（奇数尺寸、负坐标、多屏）的分区正确、默认与本次运行内上次模板、指针换屏现算。 |
| drag-placement-state | 状态机：进入/退出（松辅助键、Esc、结束拖动）、先按住后拖动、指针命中与缩略图切换、不合格源不进入。以合成事件流驱动。 |
| drag-placement-settings | 辅助键默认值、自定义单键/组合键、恢复默认；现有四项注册与主题不受影响。 |

共享回归沿用现有 screen-arrange、screen-guard、recent-group、shortcut-settings、settings-ui、maximized 等 case。覆盖层界面用现有命令级检查方式；真实视觉、手感、系统事件送达与贴边竞争属人工验收与实机验证，不伪造通过。本轮只发布规格，未运行任何产品检查。

## Out of Scope

循环粒度手势（拖出再拖回换 1/2、1/3、2/3）、拖动中数字键/滚轮切换模板、模板持久化偏好、反向模板变体（如 1/3+2/3）、旧 Ctrl+Alt+3 位置图入口、纯键盘放置、连击检测、跨虚拟桌面投放、修改或最小化原占用窗口、多级连续撤销、把源窗口加入最近窗口组、托盘小图标与窗口常驻方式（另行处理）、macOS、安装与发布。

## Further Notes

- 本规格只综合本轮访谈已确认的决定；标注"关键取舍"中关于最小尺寸、缩略图条默认置于屏幕顶部居中（实施时可按设计稿调整）、覆盖层纯视觉不消费输入三项为规格补充的默认处理，未单独逐条访谈，实现或评审时可提出异议。
- 实现阶段需实测的边界：系统移动/缩放事件与指针、键状态的组合能否可靠区分"松手提交"与"Esc 取消"（事件本身不区分）；屏幕边缘分区上松手时与 Windows 自身贴边的竞争，需确保 PaneSet 几何最终生效；覆盖层在第三方置顶窗口之上的可见性；混合 DPI 跨屏分区计算沿用现有坐标合同。
- 证据边界：本轮无任何实机运行；交互结论来自访谈与既有调研（Loop 的预览与方向选择、词表参考见 docs/RESEARCH_SHORTCUTS.md），不证明效率优势。此前独立试验的三项人工判断仍未完成，不由本规格补写。
- 交互讨论全过程与 Q1–Q17 的逐条记录见 [interaction-notes.md](interaction-notes.md)。

# 两窗排布与恢复

Status: ready-for-agent
Progress: done

用户已确认 docs/SETUP_REVIEW.md 中的配置、交付和两个测试边界。本任务是单次可运行交付，直接按 implement/tdd 推进。

## 交付

- 原生 Windows 选窗面板，当前桌面和目标显示器内的独立窗口按应用和标题展示，支持搜索。
- 选择两窗、交换左右顺序，面板内显示整组并排预览。取消不移动窗口。
- 确认后读取最新快照，再排布目标。报告实际结果，未选窗口不受影响。
- 恢复最近一次排布受影响的存活窗口，恢复正常或最大化状态，身份失效时跳过。
- 窗口操作阻塞时界面继续响应，保留快照和未完成操作，完成前阻止冲突操作。
- 提供局部工具链、启动和验证入口，记录实际支持范围。

## 已确认测试边界

布局生成的公开输出，以及真实受控窗口的枚举、快照、应用和恢复。使用独立进程创建验证窗口，测试已最大化目标、部分排布失败、延迟响应、关闭或身份不匹配目标和未选中的第三扇窗口。

## 快速开始

固定版本的 Windows x64 本地试用包见[试用说明与已知限制](docs/TRIAL.md)。ZIP 内自带 .NET 运行时，完整解压后运行 `PaneSet.exe`。

从源码构建时，双击运行根目录的 [run.cmd](run.cmd)。

- **首次运行**：会自动下载并配置免安装的本地 .NET 环境，无需手动配置全局开发环境。
- **重复运行**：会自动唤起已有的窗口面板，不会重复启动多份实例。
- **退出程序**：在面板中点击“退出”即可完全关闭，并释放已注册的全局快捷键。

## 使用方式

### 1. 核心流程：跨屏挑窗与排布
1. **唤起面板**：按 `Ctrl+Alt+Space` 打开主面板（当前处于前台的窗口默认已勾选）。
2. **挑选窗口**：在列表中勾选需要对照的窗口（支持跨屏幕，可按应用名或标题搜索，编号代表排布顺序）。
3. **选择布局**：
   - 支持 **等宽并排**（`Alt+1`）、**一主多辅**（`Alt+2`）、**网格**（`Alt+3`）或 **自动**（2~3 窗自动并排，4 窗及以上自动网格）。
   - 右侧可即时预览排布效果；按 `Alt+S` 可快速轮换窗口位置。
4. **一键排布**：选择目标屏幕，按 `Enter` 执行排布，面板自动收起。
5. **一键复原**：对比完成后，按 `Ctrl+Alt+Z`（或在面板点击“恢复上次排布”），所有受影响的窗口会立即退回各自原本的位置、大小与屏幕。

### 2. 本屏快捷操作（日常高频）
如果只想整理当前屏幕的窗口，不用打开主面板：
- **`Ctrl+Alt+1`（自动平铺）**：一键将当前屏幕的所有可见窗口自动排满。
- **`Ctrl+Alt+2`（缩略图快选）**：呼出当前屏幕的缩略图网格。即便窗口被完全遮挡在底层，也能看预览图直接点选，按 `Enter` 快速排好，按 `Esc` 取消。

### 3. 微调上一批窗口（最近组）
排布后如果还想调整这一组窗口的顺序或换个布局，打开面板点击 **“调整最近组”**，即可重新载入上一轮排布的窗口成员与设置，直接调整无需重新找窗。

## 快捷键速查

全局快捷键可在主面板的 **“设置”** 中自由修改或禁用，配置文件保存在 `%LOCALAPPDATA%/PaneSet/settings.json`。

| 作用范围 | 快捷键 | 功能说明 |
| --- | --- | --- |
| **全局** | `Ctrl+Alt+Space` | 唤起 / 收起 PaneSet 主面板 |
| **全局** | `Ctrl+Alt+Z` | 一键复原上次排布的窗口状态 |
| **全局** | `Ctrl+Alt+1` | 一键自动排布当前屏幕的所有窗口 |
| **全局** | `Ctrl+Alt+2` | 唤起当前屏幕缩略图快选面板 |
| **面板内** | `Alt+1 / 2 / 3` | 预览布局：等宽并排 / 一主多辅 / 网格 |
| **面板内** | `Alt+S` | 轮换窗口排列顺序（对调左右或将首窗移至末尾） |
| **面板内** | `Ctrl+F` | 快速聚焦搜索框 |
| **面板内** | `Tab` / `空格` | 切换焦点 / 勾选或取消窗口 |
| **面板内** | `Enter` | 确认并执行排布 |
| **面板内** | `Esc` | 收起面板（快选模式下为取消操作） |

> **提示**：若某个窗口本身有最小尺寸限制（过小无法缩放），建议改用网格布局或减少同时选中的窗口数量。

## 技术实现与验证

- **技术栈**：C# / .NET 10、WPF、Win32 API，无额外第三方运行时依赖。
- **源码结构**：主程序位于 [src/PaneSet](src/PaneSet/PaneSet.csproj)，检查与测试代码位于 [tests/PaneSet.Checks](tests/PaneSet.Checks/PaneSet.Checks.csproj)。
- **自动化验证**：双击运行 [verify.cmd](verify.cmd)，会自动运行布局计算算法与受控真实窗口交互测试。
- **实测记录**：实机截图、边界条件及完整测试记录见 [验收记录](docs/VALIDATION.md)。

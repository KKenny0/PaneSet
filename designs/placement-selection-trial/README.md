# 放置选取：Windows 交互试验

这是独立 WPF 验证程序，验证“进入选取 → 指向预览 → 点击放置”的三个体验问题。采用 PaneSet 现有浅色配色、微软雅黑和绿色目标描边，无动画。

双击 `run.cmd` 启动。它使用仓库自带的 `.tools/dotnet` 构建，产物写入临时目录。关闭任一试验窗口或点击“结束试验”会结束整次试验并保存记录。无需安装、账号或修改快捷键设置。

## 试验范围

- 三扇真实的、本进程创建的 WPF 测试窗口，可以编辑。程序只移动这些窗口。
- F8 在试验窗口内进入选取；F9 恢复最近一次实际放置；F10 重置位置。没有注册全局快捷键，与运行中的 PaneSet 分开。
- 源固定为按 F8 时的测试窗口。只允许借用源所在屏幕上另一个测试窗口的完整外框；外部窗口覆盖的区域拒绝选择。
- 选取期间由覆盖层接收输入；预览只描边。一次新鲜的主按钮按下与松开，确认已显示且仍有效的目标。拖动、目标变化或未完成显示的目标不提交。
- Esc、右键、F8、点击无效区域取消。普通取消返回源；外部激活取消且不再激活旧源。取消过程中已按住鼠标时等待松开；外部焦点或捕获丢失时停止，不能保证系统此后的鼠标消息归属。
- 这是限定为矩形测试窗口的命中策略，不能作为生产版原生命中、透明/异形第三方窗口、混合 DPI、跨屏或虚拟桌面验收。原有生产执行器、单窗规则和设置均未修改。

## 三分钟试用

先不要阅读下方实现细节。任务面板已列出任务；每次开始前先在“工作记录”输入一句话。

| 问题 | 任务 | 记录什么 | 中立追问 |
| --- | --- | --- | --- |
| 是否知道自己处于选取状态？ | F8 后在两份资料之间移动鼠标，停顿，再取消。 | 是否察觉进入/退出；是否把悬停当作已执行；取消后几何是否保持。 | “现在点击会发生什么？你依据什么判断？” |
| 是否知道移动谁、放到哪里？ | 选中一个位置，在点击之前先说出预测，再完成。 | 预测的源、参照及最终矩形是否与结果一致；是否误认为交换或移动参照。 | “你预计接下来会发生什么？” |
| 是否能自然继续工作？ | 放置或取消后直接续写，不主动找焦点；再测试 Alt+Tab 退出。 | 是否需要额外点击；光标是否保留；首次输入延迟；外部切换后有没有被拉回。 | “刚才有没有多做一步，或者等了一下？” |

预测任务只做第一遍。随后重置位置，再做一遍放置并直接续写，这一遍不暂停讲解、不提前报预测。将两遍的首次输入时间分别观察，避免把讲解造成的停顿算作操作打断。

然后补试右键、空白处点击、双击、按住鼠标时切换应用，以及放置后快速再点一下。测试窗口内的“测试普通按钮”会记录普通点击次数，可用来发现点击穿透。

在任务面板给三个问题分别选择答案，点击“导出本次记录”。把“哪一步犹豫/多点/等待”告诉协作者。没有用户作答前，三项体验结论均保持 pending。一次试用不能代表所有用户或环境。

## 连击保护的实验性取舍

确认或普通取消后，画面遮罩消失，键盘焦点立即尝试返回源；原覆盖层保留近乎透明的输入层，持续本机系统的双击间隔。本机首次观察为 500 毫秒。

这个输入层在该屏幕消费鼠标点击，收到新点击后重新计时；鼠标仍按住时不会因定时器到期而关闭。源失去前台或试验退出时清除。它也会消费一次有意的快速点击，所以必须把这种打断计入第三个问题。若发现点击被消费，松开鼠标并停止点击一个系统双击间隔，或切换到其他应用退出。真实按键、双击、捕获、激活顺序与清理仍需实机验证；模型通过不证明它们通过。

## 记录与自动检查

每次记录保存在 `%TEMP%/PaneSet-SelectionTrial/<时间与随机标识>/`。`events.jsonl` 自动记录事件，`results.json` 在启动、导出和退出时保存。记录窗口代号、几何结果、相对时间、首次输入的字符数量与焦点读数，不保存编辑器正文。人为问卷与自动事件分开保存。

`--check <输出目录>` 使用真实前台和原生命中读数，通过方法调用与坐标观察检查，不发送原生键鼠。前置条件不满足时退出 2，记为 unavailable。

`--model-check <输出目录>` 显式注入前台和命中观察，并跳过实际键盘焦点要求，调用相同手势/执行方法；测试窗口的位置修改与读回是真实的。它验证生命周期、几何、取消、拖动拒绝、目标变化、恢复与重复提交保护，不验证真实点击、焦点交接或点击穿透。

构建示例（从仓库根目录）：

```powershell
.tools/dotnet/dotnet.exe build designs/placement-selection-trial/SelectionTrial.csproj -c Release --artifacts-path "$env:TEMP/PaneSet-SelectionTrial-check" --nologo
.tools/dotnet/dotnet.exe "$env:TEMP/PaneSet-SelectionTrial-check/bin/SelectionTrial/release/SelectionTrial.dll" --model-check "$env:TEMP/PaneSet-SelectionTrial-results"
```

删除此试验目录与对应临时记录即可撤回。没有写入产品配置、替换运行程序或集成到生产快捷入口。

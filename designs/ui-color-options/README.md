# PaneSet 界面配色比较

三套方案使用相同的选窗内容，便于比较颜色、信息层级与最小窗口尺寸。

| 方案 | 常规 860 × 730 | 最小 600 × 600 | 方向 |
| --- | --- | --- | --- |
| A · 雾白工作台 | [预览](A-normal.png) | [预览](A-minimum.png) | 近白底、细边线，深青色只用于主操作和编号。 |
| B · 板岩蓝控制栏 | [预览](B-normal.png) | [预览](B-minimum.png) | 蓝灰色承载控制区，白色窗口列表占主视觉。 |
| C · 夜航工作台 | [预览](C-normal.png) | [预览](C-minimum.png) | 深色整体界面，薄荷色提示选中和确认。 |

[打开可切换的比较页](compare.html)。比较页源码已备好，但未完成浏览器渲染验证；六张静态预览已逐一检查。

生产 WPF 界面现采用 A 作为亮色、C 作为暗色，并支持跟随系统；图标沿用 A1。

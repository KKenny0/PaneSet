## 本轮两窗交付

沿用现有 [Windows 方案](WINDOWS_PLAN.md)，本轮完成下面这条可操作的流程：

1. 手动启动原生 Windows 应用，列出当前虚拟桌面、目标显示器中的可选窗口，以应用名称和窗口标题区分。
2. 选择两扇窗口，面板内看到等宽并排的整组预览。选择顺序对应左右位置，支持交换位置。
3. 确认后修改这两扇真实窗口，读取实际结果；失败时说明对应目标的情况。
4. 恢复最近一次操作影响的存活窗口，恢复依据是在实际修改前读取的快照。

验收使用创建的受控窗口，再补充普通应用试用。取消预览时窗口不动；未选中的窗口不受影响；目标关闭时不会把操作应用到身份不匹配的窗口。

三窗布局和全局快捷键紧接这条流程扩展，产品方向和完整验收候选见已有文档。

以下保留准备阶段的调查记录。当前 SDK 与运行结果以验收记录为准。

- 主机为 Windows 10 Pro 22H2、AMD64，系统版本 19045。
- 当前会话是可交互桌面，有两台显示器，具备运行原生窗口验证的条件。
- 当前 PATH 和四个常见安装目录未发现 `dotnet`，没有安装 SDK。

- 当前 Windows 10 Pro 22H2 不在 .NET 10 官方支持的系统列表内。SDK 和原型能否在这台主机运行需要实际验证，不能把 .NET LTS 期限等同于操作系统支持期限。来源及影响见 [Windows 方案](WINDOWS_PLAN.md#验收与环境) 和 [研究依据](REFERENCES.md)。

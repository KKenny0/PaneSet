# PaneSet 0.2.0-preview.1 本地试用

这是 Windows x64 试用快照，包含设置、本屏全部排布、窗口总览和按候选数调整面板大小。它不是正式稳定版。

## 启动与切换版本

1. 把整个 ZIP 解压到一个新的文件夹，不要只取出 EXE，也不要直接在压缩包中运行。
2. 如果旧 PaneSet 正在运行，需要恢复旧布局时先点“恢复上次排布”，再在面板点“退出”。恢复记录只在进程内保存，退出即清空。
3. 双击解压目录内的 `PaneSet.exe`。包内自带 .NET 运行时，无需安装 SDK，也不会在启动时下载运行时。

程序是单实例的。旧版未退出时启动新版，只会唤起旧版，不能据此判断新版效果。新旧版本共用 `%LOCALAPPDATA%/PaneSet/settings.json`；本包不重置该配置。包未签名，Windows 是否显示安全提示由本机策略决定。

## 常用操作

- `Ctrl+Alt+Space`：打开或收起跨屏选窗主面板。
- `Ctrl+Alt+1`：排布本屏全部合格窗口，遮挡不排除；最小化、隐藏、全屏等窗口不在候选范围。
- `Ctrl+Alt+2`：打开本屏窗口总览，选择要对照的窗口，Enter 排布，Esc 取消。
- `Ctrl+Alt+Z`：恢复最近一次排布实际影响的窗口。
- 全局键可以在“设置”中修改或禁用；键位冲突时保留面板按钮入口。

总览按应用名和标题搜索，右侧前移/后移调整排布顺序。搜索不丢失已选成员。布局可选自动、等宽、一主多辅、网格。搜索框里的 Enter 不执行排布，按钮焦点上的 Enter 执行该按钮。

## 已知限制

- 正式支持目标是 .NET 10 支持的 Windows 11 x64，尚未完成该基线的全面验收。当前开发主机的 Windows 10 Pro 22H2 不在 .NET 10 官方支持列表中，能运行不代表受支持。
- 快捷键配置原子保存曾发生 Windows 错误 1175（无法删除要被替换的文件）。独立 Win32 探针也可复现，系统触发者未确定；发生保存失败时保留原绑定，不把失败当作保存成功。
- 输入检查曾发生窗口遮挡、焦点/布局键等待失败。最近五个相关定向检查通过，已增加失败现场诊断；偶发失败根因未确认，不能认定问题已消失。
- DWM 内容预览失败时可以按标题选窗；接口成功不保证受保护应用提供可辨认画面。
- 混合 DPI、显示器拔插、中文输入法组合及第三方应用尺寸约束仍需实机验证。恢复失败或部分成功会报告实际结果，不能保证所有应用接受尺寸。
- 最近窗口组和恢复记录不跨进程保存。没有自动更新、安装器或开机启动配置。

## 版本与反馈

包内 `BUILD-INFO.json` 记录版本、完整源码提交、架构和发布参数；`SHA256SUMS.txt` 可核验包内文件。反馈时保留 BUILD-INFO.json，说明触发步骤、应用、屏幕/缩放、是否使用输入法，以及预期与实际结果。

优先记录日常操作中实际遇到的误选、布局修补、恢复不准确和快捷键无响应；不要为了验证而反复移动重要工作窗口。

## 构建来源

版本号来自 `src/PaneSet/PaneSet.csproj`。试用包应从已提交源码的独立副本构建，而非混入工作区临时改动：

```text
dotnet publish src/PaneSet/PaneSet.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=false -p:PublishTrimmed=false -p:DebugType=None -p:DebugSymbols=false -p:InformationalVersion=0.2.0-preview.1+<完整提交> -p:IncludeSourceRevisionInInformationalVersion=false -o <独立输出目录>
```

打包后应重新解压，核对哈希、运行时文件和版本元数据，并运行解压目录中的 `PaneSet.exe --probe`。该参数创建并关闭一个 WPF 探针窗口，不注册全局键、不读取用户配置、不唤起或结束已有 PaneSet；它证明包可启动，不等同于完整功能验收。

# Windows 实现

PaneSet 使用 C#、.NET 10、WPF 和 Win32。初次两窗交付之后，用户明确要求改进多显示器、快捷操作和更多窗口；本轮扩展同一程序的选窗及布局能力。[产品定义](PRODUCT.md)记录行为，[验收记录](VALIDATION.md)记录运行证据。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| MainWindow | 多选、搜索、编号顺序、响应式列表、显示器及布局选择、局部键、最近组，以及设置/A/B 请求协调与结果反馈。 |
| LayoutEngine | 在物理像素工作区域内生成任意两窗以上的目标矩形，不调用系统接口。 |
| WindowManager | 枚举、身份校验、整组快照、排布读回、部分失败及恢复重试。 |
| PanelShortcuts | 独立注册四个全局动作、接收 WM_HOTKEY、绑定事务、实际状态与退出释放。 |
| ShortcutSettings / SettingsWindow | 版本化 JSON、临时文件原子替换，以及全局绑定编辑和局部作用范围说明。 |
| OverviewSelection | B 总览的固定候选、有序选组、身份刷新、搜索匹配、编号及布局确认资格；只接收观察数据，不调用系统接口。 |
| QuickSelectWindow / WindowThumbnail | 本屏不透明 WPF 总览、输入与状态呈现、DWM 内容预览及裁切释放、焦点与会话生命周期；不持有 Undo。 |
| App | 捕获启动前的前台窗口，使用会话内命名互斥量与事件保留一个进程，重复启动唤起已有面板。 |

原型只需要本地桌面能力，无外部服务、账号或 API 密钥，未引入额外第三方运行依赖。

## 显示器与候选窗口

使用 `EnumDisplayMonitors` 列出连接屏幕，读取 `GetMonitorInfo` 的工作区域，保留非零及负坐标。目标显示器默认来自面板出现前的前台窗口；该窗口不符合候选条件时回退鼠标所在屏幕，从空选择开始。初次显示和全局唤起时将面板放在该屏幕，手动切换布局目标不搬动面板。

候选窗口覆盖当前虚拟桌面的所有连接屏幕，界面标明来源。切换目标屏幕保留选择，刷新保留具有同一身份的选择及顺序；明确应用后，才把所选窗口集中到目标屏幕。

- `EnumWindows` 获取顶层窗口；排除 PaneSet 自身、工具或模态附属窗口、最小化、隐藏、不可调整大小和全屏窗口。
- `IVirtualDesktopManager.IsWindowOnCurrentVirtualDesktop` 与 DWM cloaking 排除其他桌面或系统隐藏的窗口。
- 支持普通和最大化窗口。标题用于展示与搜索，身份依据为句柄、进程、线程、进程启动时间、窗口类及会话 generation；关闭事件使旧 generation 失效。
- 被其他窗口遮挡的普通窗口仍列为候选。同一应用的每扇窗口独立选择。

这些筛选结果不构成任意应用兼容承诺。跨桌面选窗和最小化窗口唤醒未实现。

## 布局计算

当前提供自动、等宽并排、一主多辅和网格。自动布局在两三窗使用等宽列，四窗以上使用网格。网格按行排列，列数为窗口数平方根向上取整；最后一行可有空位。一主多辅将 1 号分到左侧约三分之二宽度，其余窗口在右侧纵向排列。

默认间距为 12 物理像素。分区按整数边界分配剩余像素，保证奇数尺寸、负原点、间距和区域边界正确。布局无法容纳窗口，或任何预期矩形小于 240 × 160 时，在修改前拒绝并提示减少选择或改用网格。该阈值不替代目标应用自身的最小尺寸限制。

WPF 使用设备无关单位，窗口排布使用原生物理屏幕坐标；DWM 可见边框与外框差额在 `SetWindowPos` 处换算。预览使用实际工作区域和同一布局算法，编号对应选择顺序。

## 排布与恢复

最终确认后、首次修改前获取整组最新的显示状态、可见边框及 `GetWindowPlacement`。每扇快照保存来源屏幕和排布目标屏幕。修改前仍重新检查身份、当前桌面、来源屏幕及目标工作区域，最大化窗口先转为正常窗口。

原生窗口操作在后台同步执行，`SetWindowPos` 返回成功后仍读回实际几何；700 ms 只决定是否显示等待状态。尚未完成的系统调用继续占有同一操作 guard，按钮、全局恢复和重复确认不能启动冲突修改。等待不是取消，退出也不保证已发出的请求被撤销。

首次修改之后比较整组与原始快照，记录实际改变且身份仍匹配的窗口，包括一扇窗口间接改变另一扇的情形。操作逐窗进行，保留部分结果，不承诺原子事务或捕获比较结束之后的所有延迟变化。

Undo 恢复最近一次实际受影响的目标，各自使用原始 `WINDOWPLACEMENT` 回到来源屏幕。普通顶层窗口的 placement 使用工作区坐标，不能与 `SetWindowPos` 屏幕坐标混用；恢复后比较实际边框及最大化状态。部分排布可能使窗口留在来源或目标屏幕，两者均可进入恢复校验。

身份失效则跳过，不写入另一扇窗口。显示器断开、工作区域改变或应用拒绝恢复时逐窗报告，仍有效的失败记录保留供重试；目前没有显示配置改变后的自动坐标迁移。普通权限无法控制管理员窗口时给出实际失败反馈，不自动提权。

## 面板与最近组

正常尺寸以大列表为主，宽度小于 760 设备无关单位时将目标和布局设置移到列表下方，并默认折叠预览。Alt+1/2/3 在面板内切换等宽、主辅和网格，只更新预览；精确修饰键匹配避免普通数字及组合修饰键误触发。Ctrl+F、Alt+S、Enter 和 Esc 沿用原有入口，等待期间禁止冲突操作。

MainWindow 私有保存一组成功排布的完整 WindowTarget 身份、相对顺序、目标 DisplayArea 和布局。Apply 发起时复制本次请求；Pending 反馈保留请求，直接或定时 CompletePendingAsync 收到整组最终成功才发布。失败与部分失败保留旧最近组，无变化成功也可以更新元数据；Undo 的最新快照与影响判定继续由 WindowManager 独立负责。

“调整最近组”刷新当前候选与屏幕、清除筛选，以完整身份载入有效成员并显示当前标题，不移动窗口。成员缺失不替换为同应用其他窗口，少于两扇禁止排布。目标失效及后续刷新均保持未选择，不能自动改排首屏；有效目标使用当前工作区域重新预览。枚举后窗口关闭等异常必须在 finally 释放控件更新标志，刷新后仍可正常选择。

收起保留最近组，Closed 清空成功记录和待完成请求，终局回调忽略已经关闭的面板，避免退出后重新发布。最近组不持久保存；本屏操作新增显式 `ApplyOnScreenAsync` 入口，复用同一个原生执行与恢复管理器。

## 快捷入口与生命周期

默认绑定为 Ctrl+Alt+Space 打开/收起、Ctrl+Alt+Z 恢复、Ctrl+Alt+1 本屏全部排布、Ctrl+Alt+2 本屏快速选窗。`RegisterHotKey` 附加 `MOD_NOREPEAT`，实际修饰键从配置读取。四个注册独立报告，一项冲突不阻止其他动作；设置区分保存值与实际状态，任务栏与按钮继续可用。

配置为 `%LOCALAPPDATA%/PaneSet/settings.json`，版本 1，缺失动作使用默认，显式 null 禁用；未知版本/损坏内容反馈并使用默认，不在主动保存前覆盖。修改时验证格式与自身重复，先注册暂存新组合，保留旧组合，再以同目录临时文件及原子替换保存。保存成功才发布并释放旧注册；注册/保存失败清理暂存键、保留旧绑定。默认恢复使用相同事务；清理异常显示诊断，退出仍释放持有的注册。只持久化快捷键。

全局唤起先捕获当前前台窗口，再刷新屏幕和候选列表；面板已经有焦点时收起。操作待完成时唤起只显示反馈，不重新收集选择或改变目标。明确退出时 `UnregisterHotKey` 释放注册。

关闭按钮、Esc 和“收起”最小化到任务栏，进程、最近组和恢复记录继续保留。“退出”真正结束进程并清除记录；操作仍待完成时需确认风险，默认选择不退出。没有托盘或自动开机启动，任务栏是持续可见的手动入口。

会话内仅保留一个 PaneSet 进程。重复手动启动用命名事件通知已有进程打开面板，避免多个快捷键持有者或两份恢复记录。

## 本屏全部排布与快速选窗

A/B 捕获合格前台所属屏幕，前台属于 PaneSet 或不合格时回退鼠标屏幕。捕获的 HMONITOR 和工作区固定。`ApplyOnScreenAsync` 在整组最新快照前及每扇第一次修改前复验身份、资格、所属屏幕和目标工作区，包含最大化还原前的资格复查；原跨屏 `ApplyAsync` 保留。目标环境改变停止余项，成员关闭/移屏则跳过并报告；实际影响沿用原 Undo，失配记录保留，不能擅自移回其他屏幕。

A 以合格前台为 1 号，其余按 Y、X 及本次枚举顺序排序，使用自动布局。零/一窗不修改窗口或 Undo，并显示主面板反馈；尺寸拒绝仍在任何修改前执行。A 不改变 B 的选择。

B 每次创建新的临时会话，前台合格窗口默认选中；本进程内保留 B 的布局选项，与主面板布局分开。进入时收起主面板；普通不透明 WPF 宿主按捕获的候选数计算初始尺寸并居中于目标工作区。隐藏 HWND 先移到目标屏，读取其 DPI，再将 DIP 尺寸换成物理矩形：最多三列，按卡片行数增加高度，高度最多 900 DIP，工作区四周预留约 24 DIP。两窗常规为 968×560 DIP，三窗为 1258×560 DIP，四窗为 968×724 DIP；空间不足时受工作区限制并滚动。本次搜索、选择和刷新不重新计算外框，避免跳动。合格前台卡片优先，其余按初始 Y/X/枚举顺序；点击、标题变化与失效刷新不重排卡片。候选沿用触发时捕获集合，失效卡片保留位置，未选失效卡片不可选；已选失效成员保留说明、选择及顺序并禁止确认；同一身份恢复合格后自动恢复有效性，其他条件满足时恢复确认资格。用户可主动取消，取消后不自动选回，再选加入末尾。搜索筛选不改变选择，右侧前移/后移只改编号及最终布局。候选与已选列表独立滚动，低于 600 DIP 高折叠预览。

WindowThumbnail 只持有 DWM 绘制关系；Register、QuerySourceSize、Update 与 Unregister 生命周期集中于此。按源纵横比等比缩放，将 WPF 槽位转为宿主客户区物理坐标；滚动时裁切目标矩形并对应裁切源矩形，避免绘制到标题、搜索或操作区。布局下拉打开时隐藏缩略图，选窗失效/关闭时释放。注册、尺寸查询或更新失败则保留可选标题卡片；API 成功不保证受保护应用提供可辨认内容。

覆盖层消费点击，预览不修改目标几何。Tab/Space 选择，Ctrl+F 搜索，精确 Alt+1/2/3 改预览；Enter 确认，布局下拉框打开时第一次 Enter 只接受选项。搜索框内 Enter 不提交，按钮焦点上的 Enter 执行该按钮，避免顺序调整误排布。确认先关闭覆盖层，再调用共享本屏执行；Esc 与外部失焦结束未确认选择并保留 Undo。初次显示做一次普通激活请求；实际前台和键盘焦点未取得则退出，反馈用 `ShowWindow(SW_SHOWNOACTIVATE)` 显示主面板。刷新和失焦判断不反复请求前台；内部拥有的弹出控件属于同一会话。

B 选窗、设置和原生 pending 互斥，所有成功记录与恢复快照仍由主面板和 WindowManager 协调。界面绘制与输入检查不代表混合 DPI 或第三方窗口实机验收。

## 验收与环境

布局检查覆盖不同数量、各布局、奇数尺寸、负坐标、间距、包含区域与互不重叠。真实受控 WPF 窗口检查覆盖双向跨屏正常及最大化恢复、副屏三窗、八窗网格、未选窗口保持原状、组快照、部分失败、身份变化和延迟响应。快捷键的实际按键与消息路由分别检查，后者包含冲突、收起和释放；合成 WM_HOTKEY 不证明真实按键送达。真实局部布局键、全局按键与合成路由独立报告；当前仍有输入检查失败，不能以一次通过认定历史不稳定已修复，详见验收记录。重复原生进程启动及退出重启独立检查单实例。

当前主机为 Windows 10 Pro 22H2 x64、Build 19045；两台显示器为 100% 缩放，工作区域分别为 `(0,40,2560,1400)` 和 `(2560,40,2560,1400)`，任务栏位于上方。混合 DPI、125% / 150% 缩放、左侧任务栏、负原点的实际显示拓扑及显示配置变化尚未实机验收。

项目使用 SHA-512 校验过的官方 SDK 10.0.401，位于 `.tools/dotnet/`，不修改系统 PATH。当前 Windows 10 Pro 22H2 未列入 .NET 10 的[官方系统支持列表](https://raw.githubusercontent.com/dotnet/core/main/release-notes/10.0/supported-os.md)；LTS 截止日期不代表这台主机受支持。本轮是可运行原型，未作正式发布的兼容性承诺。受支持环境验收基线为 .NET 10 官方支持的 Windows 11 x64 版本，该基线尚未运行完整检查。

产品价值仍需比较从选窗到修补、恢复的完整任务成本，不能以自动检查通过代替真实使用效率验证。

# README Showcase 录制清单（2026-11-16）

录制工具：ScreenToGif 2.43.2（已装，开始菜单可搜到）。
构建前置：运行实例已是 `96180ee`（含辅主模板）✓。
输出目录：录完直接存到 `docs\images\readme\`，文件名按下面来。

## 通用设置（三条通用）

- Recorder 选屏后：**15 fps**、缩小系数 100%（不要降采样）
- 桌面切深色壁纸；关闭通知（Win+A 开"勿扰"）；任务栏自动隐藏可开（画面更干净）
- 每条开录前**停 0.5s** 再动，结尾**停 0.5s** 再停录——给 GIF 留呼吸帧
- 完整动作一镜到底，中途不剪； ScreenToGif 编辑器里只删多余首尾帧
- 导出 GIF：文件 → 另存为 GIF，编码器选 **FFmpeg（内置）**，循环 ∞

## 镜头 1：hero.gif（≤2MB，6–8s，1280 宽单屏）

完整旅程一镜到底：
1. 桌面准备：两个普通窗口（如记事本 + 浏览器）随意错开摆放，部分重叠
2. `Ctrl+Alt+Space` 唤出面板（前台窗口自动预选）
3. 勾选第二个窗口（鼠标点复选框）
4. 按 `Enter` —— 两窗排开，面板收起
5. 稍停，按 `Ctrl+Alt+Z` —— 两窗回到原位

要点：面板出现到 Enter 之间节奏放慢些（这是观众主要看的）；还原动作明显（窗口跳动可辨）。

## 镜头 2：drag-placement.gif（≤1MB，5–7s）

1. 桌面准备：一扇已排好的窗口（占半屏），一扇随意摆的小窗（如记事本）
2. 按住 `Ctrl+Shift`（你的拖动辅助键，settings 里 modifiers=6）拖小窗标题栏
3. 分区浮现后，指针**划过顶部缩略图条**：先停在"主辅"，再划到"**辅主**"（第 4 枚，展示新模板）
4. 拖到左侧 1/3 格，保持 Ctrl+Shift 松开鼠标 —— 小窗入格

要点：换模板那步放慢（划过缩略图 → 分区切换可见）；落格瞬间窗口吸附要有 0.5s 定格。

## 镜头 3：quick-pick.gif（≤1MB，4–6s）

1. 桌面准备：3 扇窗口互相遮挡
2. `Ctrl+Alt+2` 打开缩略图快选
3. 勾两个缩略图
4. `Enter` —— 三窗排开（或勾两个排两个，看快选语义：选中的排，未选不动）

要点：缩略图网格完整入画；遮挡场景是这个功能的价值，别把窗口摆太开。

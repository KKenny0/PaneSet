## Approach

### A. 人工验收（用户操作、代理记录）

**A-0 判定标准先行**：逐项核对清单已有前置/操作/预期/证据；重点项补判定口径——
- #8/#14：恢复比较对象为**拖动开始那一刻**的位置、尺寸、正常/最大化状态；记录实际值与目标值（物理像素坐标），按 spec 口径判定；spec 未覆盖的记"待判定"并附测量值，不现场凭感觉通过；慢/快各一次只证明该两次，不排除间歇问题。
- #7 最大化源窗口：清单预期（恢复为最大化状态）与实现快照时机可能存在口径冲突——**不用实现反推验收标准**；执行时同时记录拖动前最大化状态、拖动开始后的几何及快照日志，依据 spec 澄清预期，澄清前该项判定记"待判定"。
- 鼠标操作类条目：表述同时注明"逻辑主键/次键"与"当前物理键"，防交换主次键后按错。
- 取证项（#14 及一切失败复现）：日志记录本轮时间范围、构建、对应条目编号，防旧日志混淆。

**A-1 拖动投放核心 5 项**（顺序有依赖，按此排）：
1. 先做**不需要恢复记录**的项：#5 Esc 取消、#11 屏幕边缘与 Windows 贴边竞争；
2. **带 `PANESET_DRAG_DEBUG=1` 重启实例**（在建立任何恢复基线之前完成，重启清空恢复记录无副作用），重启后确认新 PID、构建版本、辅助键配置与本轮日志**实际写入**（不能只确认启动命令带了变量）；
3. 再做恢复基线项，**每个用例重新建立并记录自身基线**：#7 最大化投放后恢复、#8 恢复精度（非松手前位置）、#14 MOVESIZE 快照精度（慢/快拖动各一次，日志取证）。

**A-2 托盘核心 4 项**：#1 隐藏到托盘、#2 左键单击、#3 右键菜单、#6 Explorer 重启重挂。**#6 排在 A-1 全部完成之后**（Explorer 重启不影响恢复记录，但避免环境扰动先做拖动项）；#6 写明异常收尾：托盘图标未重现时先记录现象并**确认 PaneSet 进程是否仍存活**；仍存活则走正常退出流程关闭后再启动（避免单实例机制只唤起旧进程而未真正恢复）；结束恢复正常运行方式、关闭本轮诊断配置。

**A-3 余项**（拖动 #3 #4 #6 #9 #10 #12 #15 + 托盘 #4 #5 #7 #8）：默认同 session 顺做；用户疲劳或时间不足时可留后续，逐项记"未执行：留后续"，不空缺。

**结果分类**：通过 / 未通过（现象+复现条件+证据）/ 阻塞（受同一故障影响无法执行，与"未执行"分开）/ 未执行（原因）。失败项不在验收现场修码：记录后开对应 `.scratch/<feature>/issues/` 新任务文件（hunt 流程留待后续 session），现场只收集证据。混合 DPI 变体待执行前提 3 确认后定记法。

**记录落点**：两份清单"结果"列逐项更新；`docs/VALIDATION.md` 末尾按既有格式追加本轮一节（区分被测构建、用户操作与机器证据）；单次通过不宣称整体通过。
